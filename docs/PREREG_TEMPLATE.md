# Pre-registration (fill in and commit BEFORE measuring)

An empty field means the measurement does not start.

1. **Why should money be here?** One sentence: who leaves this return on the table, and why.
   "It backtested well" is not a sentence.
2. **When is that sentence false?** Competition, fee changes, regime end. If it is already false, stop.
3. **Is it a variant of something already rejected?** Link the rejection and say what is different.
4. **Where do the thresholds come from?** Cost, break-even, physical limits. If from a grid, state the grid size.
5. **Measurement and verdict (fixed now):** three windows (all / 2024+ / 2025+) · best day removed ·
   random-null percentile · expected wealth (3-year block bootstrap) · the exact sentence that means "pass".
6. **If it survives:** start at minimum size; do not scale until live fills match the model.

Budget: three pre-registrations per quarter. Every attempt, including failed ones, is counted
when estimating how much of the final Sharpe ratio is luck (deflated Sharpe).
